PostgreSQL, Redis, backend và Nginx nằm trong docker-compose.yml, không cần cài MySQL.Android Studio, để mở thư mục mobile-app và chạy ứng dụng cho nhân viên lắp ráp. Ứng dụng yêu cầu Android từ API 24 trở lên.ngrok chỉ cần khi điện thoại ở mạng khác máy chủ. Trong đồ án đã có file ngrok.yml và scripts/ngrok.ps1.Bước 2: Cấu hìnhTại thư mục gốc của đồ án, copy file mẫu thành file môi trường bằng lệnh:copy .env.example .envCác giá trị mẫu dùng được ngay khi chạy bằng Docker:POSTGRES_USER=mrp POSTGRES_PASSWORD=mrp123 POSTGRES_DB=mrp_pc DATABASE_URL=postgresql://mrp:mrp123@postgres:5432/mrp_pc REDIS_URL=redis://redis:6379 PORT=3000SESSION_SECRET và JWT_SECRET giữ như trong file mẫu khi demo trên máy local. Host postgres và redis là tên service trong Docker. Không đổi hai host này thành localhost khi chạy bằng docker compose.Ảnh linh kiện nằm trên Cloudflare R2. Muốn hiện ảnh thì điền R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_BUCKET và R2_PUBLIC_URL. Chưa có R2 thì web vẫn đăng nhập và thao tác được. Lệnh tạo dữ liệu mẫu có thể báo lỗi ở bước cuối khi kéo ảnh.Trong ứng dụng Android, mở file NetworkModule.kt và sửa BASE_URL. Địa chỉ phải có dấu / ở cuối.Máy ảo Android Studio dùng địa chỉ: http://10.0.2.2:3000/Điện thoại thật, cùng mạng Wi-Fi với máy tính, dùng địa chỉ: http://<IPv4 của máy tính>:3000/Trên Windows, xem IPv4 bằng lệnh ipconfig. Điện thoại và máy tính phải cùng một mạng. Nếu dùng ngrok, gán BASE_URL bằng đường dẫn https mà ngrok cấp, vẫn có dấu / ở cuối.Bước 3: Chạy đồ ánMở terminal tại thư mục gốc, rồi chạy lần lượt:docker compose up -d --builddocker compose exec backend npx prisma migrate deploydocker compose exec backend npm run prisma:seedLệnh đầu dựng PostgreSQL cổng 5432, Redis cổng 6379, backend cổng 3000 và Nginx cổng 80. Lệnh thứ hai tạo bảng. Lệnh thứ ba tạo dữ liệu mẫu.Kiểm tra máy chủ bằng cách mở http://localhost:3000/health. Kết quả đúng là {"ok":true,"service":"mrp-pc-backend"}.Web quản trị mở tại http://localhost/admin/auth/login. Vào thẳng backend thì dùng http://localhost:3000/admin/auth/login.Tài khoản mẫu, mật khẩu cả ba tài khoản là admin123:admin là Quản trị viên, dùng trên web.warehouse là Quản lý kho, dùng trên web, đường dẫn /warehouse.staff là Nhân viên lắp ráp, dùng trên ứng dụng Android. Tài khoản này không có quyền trên web.Chạy ứng dụng: mở thư mục mobile-app bằng Android Studio, chọn máy ảo hoặc điện thoại đã bật gỡ lỗi USB, rồi bấm Run.Khi điện thoại không cùng mạng với máy chủ, ở thư mục gốc chạy:powershell -File scripts\ngrok.ps1Máy cần đã có authtoken của ngrok. Lệnh này mở đường dẫn tới cổng 3000.Bước 4: Sử dụngQuản trị viên đăng nhập bằng tài khoản admin.Đăng nhập web.Vào Tài khoản để tạo, sửa, khóa hoặc mở khóa tài khoản.
